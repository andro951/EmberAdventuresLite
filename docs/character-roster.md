# Included character roster

40 standalone characters: 20 male and 20 female, counted by authored gender. Alternate presentations remain available.

Selected for practical clothing, ordinary overall proportions, and story hooks built around work, exploration, community, and mystery. The remaining roster includes humans, dwarves, elves, dragonborn, merfolk, and other fantasy or science-fiction characters. Ordinary athletic, stocky, and soft builds are retained.

All retained canonical and alternate outfits were reviewed. No retained character file contains a hosted image URL. Story files and their embedded casts are separate from this standalone roster.
